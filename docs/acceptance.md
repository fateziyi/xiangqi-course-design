## 最终审查修复（2026-10-15）

本轮审查曾实际出现：51 项测试中 49 项通过、2 项原生引擎相关错误，其中真实原生搜索在初始化等待 readyok 时超时；单独复测曾通过，属于间歇性故障。另复现了回放推荐失败后，实际棋盘与显示步数不一致的问题。以上不以历史成功记录代替修复。

- 皮卡鱼初始化独立限时 5 秒，完成后再计完整搜索预算；搜索/校验额外留 1 秒，后端等待同步为思考预算加 6.5 秒。初始化和搜索超时分别显示，保持取消和子进程回收。新增故意延迟 readyok 1.6 秒的真实引擎全链路测试，以及初始化挂起超时回收测试。
- 回放推荐失败保留 control、displayPly、board、lastMove、行棋方及历史；错误后仍可导航与导出。自动行棋失败继续暂停。
- 安装脚本实际探测 `.venv` 是否可执行；失效时先验证替代 Python，再保留原目录为 `.venv.backup-*`，创建新环境。替代 Python 无效时不移动旧环境。隔离目录内使用真实 pip 和已有锁定依赖组装的本地 wheel 离线验证，未删除生产环境。
- 启动器使用 Windows Job Object，进程以挂起状态创建、加入 Job 后才执行，消除 Python 启动器提前生成未托管子进程的窗口。Ctrl+C 的 finally 及启动器意外退出均会关闭 Job，清理本次服务及后代；不按名称批量结束其他程序。真实测试启动三服务、发起 10 秒原生搜索、强制结束启动器后，已确认所记录的后代进程全部退出、三个临时端口释放。
- Windows PowerShell 5.1 测试另发现 UTF-8 无 BOM 及 Python `-c` 双引号参数问题，已修正脚本编码与参数引用。

验证：`python -m unittest discover -v` 全量 56 项通过，186.660 秒；自研和混合引擎各完成 100 合法半回合。全量运行后，最终启动器及离线迁移逻辑另单独复测通过。前端 `npm.cmd run build`（含 TypeScript 检查）通过。完整测试日志保留在 `.runtime/review-final-tests.log`。
